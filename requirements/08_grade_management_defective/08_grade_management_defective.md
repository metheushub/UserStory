# User Story: 成績管理功能

## 基本資訊
- **ID**: US-008
- **版本**: Release_3.1
- **狀態**: Pending
- **優先順序**: High

## User Story 描述

**作為** 授課教師

**我想要** 新增、修改、查詢與匯出學生成績

**以便於** 掌握學生學習表現並據此調整教學

## 接受標準

1. [ ] 教師可新增學生某項成績，並可修改已存在的成績；儲存後再次查詢時應顯示更新後的分數。
2. [ ] 成績分數必須介於 0 至 100（含）之間；輸入低於 0 或高於 100 的分數時，系統不得接受該筆成績，並提示輸入錯誤。
3. [ ] 教師可依學生姓名或成績項目查詢成績，查詢結果須列出符合條件的學生、成績項目及分數。
4. [ ] 每次成績新增或修改後，系統須保留異動時間及執行異動的使用者，以供追蹤。
5. [ ] 教師可匯出查詢結果；匯出內容須包含學生姓名、成績項目及分數，且與畫面上的查詢結果一致。

## 相關資訊

**衝突**: 目前未發現

**依賴**: 教師須具備該課程的成績管理權限

**備註**: 本需求範圍以授課教師為主；若課程助教也需要管理成績，應另行確認其可執行的操作與權限。
